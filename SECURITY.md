# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

**Please do not create public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability in this project, please report it by emailing:

**security@viriatosecurity.com**

Include as much detail as possible:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if any)

## Response Time

We aim to respond within **48 hours** of receiving your report. You will be kept informed of progress as we investigate and address the issue.

## Disclosure Policy

We follow responsible disclosure. Once a fix is available, we will coordinate a disclosure timeline with the reporter. We appreciate your patience and your contribution to keeping this project secure.
