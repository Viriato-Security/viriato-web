# Viriato Security

> Kernel-level AI observability and EU AI Act compliance platform.

Built in Lisbon, Portugal. Defending AI systems the way Viriato defended Lusitania — with intelligence, not brute force.

## What is this?

This repository contains the official website for [Viriato Security](https://viriatosecurity.com), built with React and TypeScript, deployed on Cloudflare Pages.

## Tech stack

- React 18 + TypeScript
- Vite
- Cloudflare Pages

## Development

```bash
npm install
npm run dev
```

## Deployment

Automatically deployed to [viriatosecurity.com](https://viriatosecurity.com) on every push to `main` via Cloudflare Pages.
